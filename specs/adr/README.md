# Registros de decisões arquiteturais

ADRs registram decisões técnicas relevantes, seu contexto e consequências. Uma decisão substituída não é apagada; recebe referência para o ADR que a substituiu.

## Estados

- Proposto.
- Aceito.
- Substituído.
- Rejeitado.
